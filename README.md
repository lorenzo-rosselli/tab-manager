# tab-manager
Tab Manager è una piccola applicazione web, personale e locale, per scrivere, archiviare ed esportare in Word (.docx) tabulature per basso e chitarra.  L'app non cerca e non genera le tabulature da sola. È l'utente che le scrive o le incolla, e l'app le salva in un archivio e le impagina in un documento Word pronto da stampare o da modificare.
